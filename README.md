# Florist Admin Platform

Plataforma Full Stack para gerenciamento de uma floricultura.

Este projeto será uma evolução do Florist Catalog, adicionando um painel administrativo para permitir que a própria floricultura gerencie seus produtos e informações.

## Funcionalidades planejadas

### Loja

- Catálogo de produtos
- Pesquisa
- Filtros por categoria
- Detalhes dos produtos
- Carrinho
- Pedidos pelo WhatsApp
- Instagram
- Google Maps
- Layout responsivo

### Painel Administrativo

- Login administrativo
- Cadastro de produtos
- Edição de produtos
- Exclusão de produtos
- Alteração de preços
- Alteração de descrições
- Gerenciamento de categorias
- Controle de disponibilidade
- Upload de imagens

## Tecnologias planejadas

### Front-end

- React
- Vite
- JavaScript
- Bootstrap

### Back-end

- Node.js
- Express

### Banco de dados

- PostgreSQL

## Status

Em desenvolvimento.

O desenvolvimento deste projeto será iniciado após a conclusão da versão inicial do Florist Catalog.
